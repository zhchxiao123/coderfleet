# 平台助手按需 MCP 重构

## 目标

根据已确认架构，将 CoderFleet 聊天和任务通过宿主 MCP 暴露给隔离容器里的 Claude Agent SDK。先完成“检索聊天 → 整理总结 → 保存到忆屿”。CoderFleet 负责数据、权限和持久化，SDK 决定如何检索及调用工具；外部 MCP 负责实际记录操作。

## 验收边界

- 查询创建不扫描全部聊天日志，不向模型预填全量历史问答。
- 有目录/定位、实际聊天搜索、Task/Conversation 分页阅读、历史回复按需阅读。
- 仅暴露授权的公开内容，保留时区、截止时间和脱敏；来源和覆盖率不造假。
- MCP 使用运行级凭证，不把操作者 API Key 交给 SDK；越范围、伪造凭证、终态访问应拒绝。
- 保留用户现有 Task 执行边界、容器及 relay/代理；不挂载业务目录或 Docker socket。
- 显式接入账号已有忆屿 HTTP MCP，复用 OAuth；服务配置不出现在公开 API 中。
- 保存历史总结无需重扫全库，也不能因空活动来源被误判为报告失败。根据真实工具回执反馈成功、失败或收件箱待收下。
- 稳定请求身份防止刷新/同请求重复执行；写入使用服务支持的幂等字段，不自动重放未知结果。
- CLI/Web 等价；界面使用一个输入框，连接设置放在“更多”。
- 原日报与已有结果兼容，自动日报不调用外部写入工具。

## 验证

Task/FakeRuntime 和真实 MCP HTTP 协议回归，隔离浏览器交互，严格类型检查及完整测试套件。真实 SDK 用模拟聊天和隔离忆屿协议服务验证总结原文保存及幂等；真实忆屿只做认证与工具协议只读核验，测试不创建真实用户记录。
