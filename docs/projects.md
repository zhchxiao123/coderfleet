# 项目

一个项目 = 一个目录 + 一个账号 + 一个容器。项目目录挂载到容器的 `/workspace`，AI 在容器里读写它。

在「设置 → 项目」里管理。

## 新建项目

| 字段 | 说明 |
| --- | --- |
| 项目名 | 字母、数字和连字符，不能重复 |
| 账号 | 这个项目用哪个账号的额度 |
| 项目目录 | 后端那台机器上的绝对路径，目录必须已存在 |
| 创建后立即启动容器 | 勾上就不用再手动启动 |

同一个目录可以建多个项目，各用不同的账号。这样一个账号额度用完时可以换另一个接着做，[做完为止](jobs.md) 的核对也会用到另一个账号。

## 容器

项目行上的主按钮在容器运行时是「对话」，否则是「启动」。菜单里还有：

- **停止容器 / 重启容器**
- **打开终端**：进入容器的 shell，`/workspace` 就是项目目录。
- **环境变量…**：只给这个项目的变量，优先于账号里的同名变量。保存后重启容器生效。
- **挂载目录…**：把机器上的其他目录挂进容器，可以设为只读。路径不能含空格或逗号。
- **允许机器操作…**：见 [机器助手](helper.md)。
- **停用项目 / 启用项目**：停用后不再启动容器，配置保留。
- **删除项目**：删除容器并从配置里移除，项目目录和账号数据都保留。还有对话在运行时不能删。

在容器里用 `sudo` 安装的软件会一直保留到容器被重新创建。

## 只能在配置文件里设置的选项

下面这些目前没有界面，需要直接编辑工作区里的 `projects.conf`（每个项目一行，`键=值` 用两个空格分隔），改完在 App 里重启项目。

| 键 | 作用 |
| --- | --- |
| `SECONDARY_ACCOUNTS=名称1,名称2` | 把其他类型的账号也挂进这个容器；同一类型只能有一个 |
| `IMAGE=镜像名:标签` | 这个项目用自己的镜像，而不是共享镜像 |
| `IDE=on` | 在容器旁启动 code-server；`IDE_PORT` 可指定端口（1024–65535） |
| `DOCKER_SOCKET=/var/run/docker.sock` | 把 Docker socket 挂进容器，让 AI 能操作 Docker |

!!! warning
    把 Docker socket 交给容器，等于让容器里的 AI 能控制这台机器上的全部容器，按需开启。

## 镜像

所有项目默认共用一个镜像，在「设置 → 通用 → 高级 → 工作区与镜像」里下载或者自己构建。「下载镜像」取的是随 App 每个版本发布的现成镜像，按这台机器的芯片（Intel / AMD 或 ARM）自动选择。镜像基于 Ubuntu 24.04，带有：

- 各家编程 CLI：Claude Code、Codex、OpenCode、Hermes、Grok、Kimi、Pi、Antigravity
- 运行时：Node.js 22、Python 3.12、Rust、Java 21 和 Maven
- 工具：`gh`、FFmpeg、LibreOffice、Playwright 和 Chromium、code-server

想改镜像里装的东西，就改工作区里的 `Dockerfile`，然后点「自己构建」并重启项目。之后再点「下载镜像」会换回现成的镜像。
