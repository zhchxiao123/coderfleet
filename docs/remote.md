# 远程机器

App 和后端是分开的。后端和 Docker 可以在另一台 Linux 机器上，App 留在你的电脑上，一个 App 可以保存多个后端并随时切换。

在「设置 → 通用 → 后端连接」里管理，也可以点左侧图标栏的后端按钮切换。

## 通过 SSH 添加

远程机器需要：Linux（x86_64 或 arm64）、已安装 Docker、登录用户能直接使用 Docker。你的电脑要已经能用密钥登录它（`ssh-copy-id user@host`）。App 不保存密码。

点「通过 SSH 添加」，填写：

| 字段 | 说明 |
| --- | --- |
| 名称 | 显示用 |
| SSH 主机 | `user@host`，或 `~/.ssh/config` 里的别名 |
| 端口 | 默认 22 |
| 密钥文件 | 可选 |

点「连接并安装」后，App 会：

1. 检查那台机器的系统和 Docker。
2. 上传自带 Node.js 运行时的后端，那台机器不需要另外装 Node.js。
3. 安装到 `~/.coderfleet-backend`，并启动为系统服务（没有 systemd 时作为后台进程运行，机器重启后需要重新启动）。
4. 把访问令牌存进你电脑的系统钥匙串，并通过 SSH 隧道连接。隧道断了会自动重连。

远程机器上不会对外开放任何端口：后端只监听本机回环地址，所有访问都走 SSH。

## 升级

App 带的后端比远程机器上的新时，这个连接上会出现「升级到 …」。升级会保留令牌、工作区和对话；容器里正在进行的回答不受影响。

## 自己部署的后端

已经把后端部署在 HTTPS 后面时，用「已有服务地址和令牌」添加。部署方法见 [后端命令行](cli.md)。

## 移除连接

「移除连接」只删除 App 里保存的这条连接，远程机器上的后端和数据都保留。
