# 机器助手

容器里的 AI 默认碰不到容器外面。机器助手让它在你允许的范围内，在后端那台机器上运行命令，例如编译原生 App、烧录开发板、读串口。

目前只支持走 relay 的 Claude Code 账号。

## 开启

1. 「设置 → 通用 → 机器助手」点「安装并启动」。如果提示「relay 还没有转发到机器助手」，点「重启 relay」。
2. 在要用它的项目菜单里点「允许机器操作…」并确认。

只对之后开始的回答生效。要收回时，在项目菜单里点「关闭机器操作」。

## 规则

在机器助手的「规则」里设置哪些命令能运行：

- 每个命令可以设为「直接运行」「先问我」或「不允许」，还可以限定只在带某些词时适用。
- 「没有单独设置的命令」统一怎么处理也在这里设；设成「不允许」就变成白名单。
- `sudo`、烧写 efuse 这几类操作不管怎么设置都不会运行。

默认所有命令都能运行，建议在允许某个项目之前先把规则收紧。

设为「先问我」的命令运行前，对话里会出现确认卡：「允许这一次」「这个任务里同样的命令都允许」或「拒绝」。

运行过的命令记录在「最近的操作」里。
