# 第一次使用

从打开 App 到发出第一条消息，大约需要十分钟，其中大部分时间在等镜像下载。

## 1. 选择后端

App 第一次打开是欢迎页，有三个选择：

- **使用这台电脑**：Docker 就在这台电脑上，选这个。App 会自己启动后端，工作区放在 `~/.coderfleet`。
- **通过 SSH 连接远程机器**：Docker 在另一台 Linux 上，见 [远程机器](remote.md)。
- **使用服务地址和令牌**：连接你自己部署的后端。

## 2. 初始化工作区并下载镜像

进入后是「项目」页，顶部会按顺序提示还缺什么：

1. **连不上 Docker**：先启动 Docker Desktop 或 OrbStack。
2. **工作区还没有初始化**：点「初始化」。App 会在工作区里创建配置文件和镜像构建文件。
3. **还没有容器镜像**：点「下载镜像」。App 会下载和这台机器的芯片相配的现成镜像（几个 GB），日志窗口可以关掉，下载在后台继续，进度显示在侧边栏底部。

!!! tip "下载不了，或者想改镜像里装的东西"
    点旁边的「自己构建」，在这台机器上用工作区里的 `Dockerfile` 构建，需要十几分钟。Apple 芯片的 Mac 自己构建前，先到「设置 → 通用 → 高级 → 代理与容器」把「镜像平台」改成 `linux/arm64`，否则容器会在模拟下运行，明显变慢（下载镜像时这一项会自动设好）。

如果宿主机代理不在 `7890` 端口，也在同一处改「代理端口」。详见 [网络与代理](network.md)。

## 3. 添加账号

「设置 → 账号 → 添加账号」：

1. 选类型（Claude Code、Codex CLI 等）。
2. 起个名称，只能用字母、数字和连字符。
3. 选认证方式：「登录账号」或「API Key 等环境变量」。
4. 网络保持「经 relay（推荐）」。

选了「登录账号」的，在账号列表里点「登录」，在弹出的终端里按提示完成授权。详见 [账号](accounts.md)。

## 4. 新建项目

「设置 → 项目 → 新建项目」：填项目名、选账号、选项目目录，勾上「创建后立即启动容器」。

项目目录会挂载到容器的 `/workspace`。详见 [项目](projects.md)。

## 5. 开始对话

容器启动后，点项目行上的「对话」，或点左上的「新对话」并选择项目，然后直接输入要做的事。

AI 要运行命令或修改文件时会停下来等你点「允许」。详见 [对话](chat.md)。
