# 常见问题

## 连接

**连不上「本机」**

点「重启本机后端」。还不行的话看 App 数据目录里的 `backend.log`。

**「连不上 Docker」**

先启动 Docker Desktop 或 OrbStack。Linux 上确认当前用户能直接运行 `docker ps`（通常需要加入 `docker` 组并重新登录）。

**「SSH 登录被拒绝」**

App 只用密钥登录，不保存密码。先执行 `ssh-copy-id user@host`，确认在终端里 `ssh user@host` 不需要输入密码。

**「服务令牌不对」**

在「设置 → 通用 → 后端连接」里移除这个连接，再重新添加。

## 镜像和容器

**下载镜像很慢或失败**

镜像放在 GitHub 的容器仓库（`ghcr.io`），下载走 Docker 自己的网络。可以在 Docker Desktop 的设置里给 Docker 配上代理；或者在「设置 → 通用 → 高级 → 代理与容器」把「镜像下载地址」换成一个镜像站上的同名地址，再点「下载镜像」。还是不行就点「自己构建」。

**自己构建镜像很慢或失败**

构建同样走 Docker 自己的网络。给 Docker 配上代理，或者换一个能访问软件源的网络，然后重新构建。

**Apple 芯片上容器很慢**

镜像是按 `linux/amd64` 自己构建的，在模拟下运行。在「设置 → 通用 → 高级 → 工作区与镜像」点「下载镜像」（会换成和芯片相配的镜像），或者把「镜像平台」改成 `linux/arm64` 后重新构建；然后重启项目。

**容器里访问不了外网**

- 宿主机代理是否在运行，并打开了「允许局域网连接」。
- 「代理端口」是否和代理软件的 HTTP 端口一致。
- 改完后重启项目。

**在容器里装的软件不见了**

用 `sudo` 装的软件在容器被重新创建后会丢失。长期需要的软件写进工作区的 `Dockerfile`，然后自己构建镜像。

## 账号

**额度不显示**

只有以登录方式认证的 Claude Code 和 Codex 账号有额度显示，并且需要这个账号至少有一个项目容器在运行。提示「登录已过期」时重新登录。

**Codex 能不能用 API Key**

不能，Codex CLI 账号只支持登录账号。

## 对话

**「做完为止用不了」**

项目目录必须是 git 仓库的根目录、至少有一次提交，容器在运行，账号是 Claude Code 或 Codex。

**「最多排队 5 条消息」**

等当前回答结束，或取消几条排队中的消息。

**「翻译成中文」不能用**

先在「设置 → 通用 → 翻译与命名」里配置模型和 API Key。

**定时没有按时运行**

后端没开着的时候不会运行；上一次还没做完时这一次会跳过。在这条定时的「历次运行」里能看到原因。

## 手机

**「这台手机的令牌已失效」**

这台手机被吊销了，或后端换过。在电脑上重新「添加手机」并扫码。

**iOS 收不到通知**

iOS 会在 App 进后台几十秒后把它挂起，之后本地通知不再触发。打开 App 就会刷新。

## 从旧的命令行版本升级

App 直接读取原来的工作区（`~/.coderfleet`），账号、项目和历史对话都在。不要让旧的 `coderfleet server` 和 App 同时运行在同一个工作区上；App 检测到时会提示，按提示停掉旧服务。
