# 账号

一个账号对应一份第三方 CLI 的登录数据（或一组 API Key）。每个账号的登录数据只挂载到它自己的容器里。

在「设置 → 账号」里管理。

## 添加账号

| 字段 | 说明 |
| --- | --- |
| 类型 | Claude Code、Codex CLI、Antigravity CLI、OpenCode、Hermes Agent、Grok Build、Kimi Code、Pi Agent |
| 名称 | 字母、数字和连字符；App 会建议 `claude`、`claude-2` 这样的名字 |
| 认证方式 | 「登录账号」或「API Key 等环境变量」。Codex CLI 只支持登录账号 |
| 环境变量 | 选了 API Key 方式时填写，例如 `ANTHROPIC_API_KEY` |
| 网络 | 「经 relay（推荐）」或「直连」，见 [网络与代理](network.md) |

同一类型可以添加多个账号，用不同的名称区分。

## 登录

点账号行上的「登录」，App 打开一个终端并运行这个 CLI 自己的登录命令。在浏览器里完成授权，需要时把授权码粘贴回终端，完成后关闭窗口。

登录在这个账号正在运行的项目容器里进行；没有运行中的容器时会起一个临时容器，这时镜像必须已经构建好。

登录过期后，同一位置的按钮变成「重新登录」。

## 套餐额度

以登录方式认证的 Claude Code 和 Codex 账号会显示「5 小时」和「本周」的已用比例以及重置时间，对话页顶栏也有一个小标签。

- 账号至少要有一个项目容器在运行，额度才查得到。
- 账号忙的时候每 5 分钟刷新一次，空闲时每小时一次；也可以在账号菜单里点「刷新额度」。

## 修改和删除

账号行的菜单里可以「编辑环境变量」「重新登录」「刷新额度」「删除账号」。

删除账号前要先删除使用它的项目。删除后，登录数据仍保留在工作区的 `accounts/<名称>/` 里，需要的话自己删除。
