# 定时

到点自己开一个新对话去做事，例如每天早上整理昨天的提交、每周检查一次依赖更新。每次运行都是一个普通对话，出现在对话列表里。

左侧图标栏点「定时」进入。

## 新建定时

| 字段 | 说明 |
| --- | --- |
| 项目 | 在哪个项目里做 |
| 要做的事 | 发给 AI 的内容 |
| 什么时候 | 「每天」某个时间、「每周」某几天的某个时间，或「每隔几小时」（1–168，从保存时算起） |
| 做完为止 | 勾上后按 [做完为止](jobs.md) 的方式做 |

时间按后端那台机器的时钟。不勾「做完为止」时，它使用工具不会停下来问你。

每一行有开关，菜单里有「立即跑一次」「编辑」「历次运行」「删除」。

## 运行规则

- 后端没开着的时候，到点不会跑。重新开着以后只补最近的一次，晚了超过一天就不补。
- 上一次还没做完时，这一次跳过。
- 项目容器没在运行时会自动启动，最多等 3 分钟。
